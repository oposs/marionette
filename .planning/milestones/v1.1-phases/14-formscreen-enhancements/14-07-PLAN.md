**Part A — Create `frontend/src/lib/components/form/FieldSet.svelte`:**

```svelte
<script lang="ts">
	import * as Field from '$lib/components/ui/field';
	import type { ComponentAction } from '$lib/transport/messages';
	import type { Snippet } from 'svelte';

	let {
		props = {},
		bind,
		action,
		surface,
		children,
	}: {
		props: Record<string, unknown>;
		bind?: string;
		action?: ComponentAction;
		surface: string;
		children?: Snippet;
	} = $props();

	let cols = $derived(props.cols as number | undefined);

	// D-C3 default: 1-col mobile, 2-col desktop.
	// D-C4 override: explicit `cols` uses inline style with static 'grid gap-4' class.
	// Pitfall #1: Tailwind v4 JIT can't resolve dynamic `grid-cols-{N}` class names —
	// inline `grid-template-columns` is the required workaround.
	let gridClass = $derived(
		cols ? 'grid gap-4' : 'grid grid-cols-1 md:grid-cols-2 gap-4'
	);
	let gridStyle = $derived(
		cols ? `grid-template-columns: repeat(${cols}, minmax(0, 1fr))` : undefined
	);
</script>

<Field.Set>
	{#if props.legend}
		<Field.Legend class="font-semibold">{props.legend}</Field.Legend>
	{/if}
	{#if props.description}
		<Field.Description>{props.description}</Field.Description>
	{/if}
	<Field.Group class={gridClass} style={gridStyle}>
		{@render children?.()}
	</Field.Group>
</Field.Set>
```

**Critical details:**

1. `class="font-semibold"` on Field.Legend overrides shadcn's default `font-medium` to comply with Phase 11's "no weight 500" rule (14-UI-SPEC.md §Typography rule 1 + Assumption A1). If the Field.Legend primitive doesn't accept `class` as a cascading override (shadcn-svelte usually does via `cn()` merge), add a wrapping span or apply `font-semibold` to the whole Field.Set via its `class` prop.
2. Children rendered via `{@render children?.()}` — NodeRenderer already resolves child node ids into a Snippet before invoking this component. Same adjacency-list pattern as Container.svelte.
3. `bind` and `action` are declared in `$props()` for SDUI contract consistency but are NOT used — FieldSet is a passive structural container.
4. `cols` is typed as `number | undefined`; the `$derived` expression uses truthy check (`cols ? ...`) which correctly treats `undefined` AND `0` as "use default". If handlers need `cols=0`, this interpretation must change, but 14-CONTEXT.md D-C4 doesn't allow 0 as a valid column count — skip.
5. `style` attribute uses Svelte's `style={...}` shorthand — Svelte handles the `undefined → no attribute` case.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Handler → frontend (props) | `legend` / `description` strings + `cols` integer flow into Field.Legend / Field.Description / inline style |
| Handler → frontend (children adjacency list) | Child node ids resolved by NodeRenderer — each child has its own trust boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-07-01 | Tampering | Text injection via `props.legend` / `props.description` into Field.Legend / Field.Description | mitigate | Svelte `{expression}` auto-escapes. Backend controls the strings. |
| T-14-07-02 | Tampering | CSS injection via `props.cols` into inline `style` attribute | mitigate | `cols` is typed `u8` in the backend (0-255 range) — Rust serde deserializes as a number, not a string. The template uses it inside `repeat(${cols}, ...)` template literal, Svelte's `style={...}` shorthand properly encodes the value. No attacker-supplied string ever reaches the style attribute. |
| T-14-07-03 | Tampering | Child node adjacency-list poisoning — handler embeds a `<script>` node | accept | Out of scope for FieldSet — child safety is each child component's responsibility. FieldSet passes NodeRenderer's Snippet verbatim. Same risk class as Container. |
| T-14-07-04 | Denial of Service | `props.cols = 255` renders 255 grid columns | accept | UX self-correcting — visible immediately; no security impact. Server handler authors choose sane values. |
</threat_model>
