# Phase 11 — UI Design Contract

> Visual and interaction contract for leaf component migration. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn-svelte 1.2.7 (via npx) |
| Preset | Default base style, Zinc, 0.25rem border-radius, CSS variables mode |
| Component library | bits-ui ^2.17.3 (headless primitives under shadcn-svelte) |
| Icon library | @lucide/svelte ^1.7.0 |
| Font | System font stack (no custom font — Tailwind default `font-sans`) |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (0.25rem) | Icon-to-label gaps inside buttons, inline padding |
| sm | 8px (0.5rem) | Compact element spacing: checkbox-to-label, label-to-input gap, input internal padding |
| md | 16px (1rem) | Default element spacing: form field gaps, card padding, dialog body padding |
| lg | 24px (1.5rem) | Section padding: dialog header/footer padding, form section gaps |
| xl | 32px (2rem) | Layout gaps: page margins, major content areas |
| 2xl | 48px (3rem) | Major section breaks (not expected in Phase 11 components) |
| 3xl | 64px (4rem) | Page-level spacing (not expected in Phase 11 components) |

Exceptions: Touch targets for interactive controls (Button, Checkbox, Select trigger) use a minimum height of 36px (9 * 4px) per shadcn default size. Icon-only buttons use 36px square (shadcn `size="icon"`).

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (0.875rem) | 400 (regular) | 1.5 (21px) | Table cells, form descriptions, toast body, error messages |
| Label | 14px (0.875rem) | 600 (semibold) | 1.43 (20px) | Form field labels, nav item text, checkbox labels, button text |
| Heading | 20px (1.25rem) | 600 (semibold) | 1.2 (24px) | Dialog titles, form section headings, Heading component (h1-h3) |
| Small | 12px (0.75rem) | 400 (regular) | 1.33 (16px) | Error validation text below fields, muted helper text |

Notes:
- Two font weights only: 400 (regular) and 600 (semibold). No weight 500 (medium) is used.
- Label text uses `font-semibold` (600), not `font-medium` (500). Any Tailwind class `font-medium` must be replaced with `font-semibold`.
- shadcn-svelte components use Tailwind's `text-sm` (14px) as baseline -- do not override this.
- Heading component renders semantic h1-h6 tags; use `text-xl` (20px) for h1/h2 and `text-base` (16px) for h3-h6.
- No Display size needed for Phase 11 (no hero/banner components).

## Color

All colors reference OKLCH CSS custom properties already defined in `frontend/src/app.css`. Components MUST use semantic token classes, never raw color values (no `text-gray-*`, `bg-red-*`, etc.).

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` / `bg-background` | Page background, surface containers, form backgrounds |
| Secondary (30%) | `--card` / `bg-card` | Card containers, table header, dialog content, sidebar background |
| Accent (10%) | `--primary` / `bg-primary` | See reserved-for list below |
| Destructive | `--destructive` / `text-destructive` | Delete buttons, error text, error icons |

Accent (`--primary`) reserved for:
- Primary action buttons (`variant="default"` — dark fill with light text)
- Active/selected nav item indicator
- Focus ring on form inputs (`--ring`)
- Checkbox checked state fill
- Sort indicator on active table column headers

Other semantic tokens in use:
- `--muted` / `bg-muted`: Skeleton loading placeholder, disabled backgrounds
- `--muted-foreground` / `text-muted-foreground`: Placeholder text, disabled text, secondary descriptions
- `--border` / `border-border`: Card borders, input borders, table row dividers, separator lines
- `--input` / `border-input`: Input field borders (slightly different from general border)
- `--popover` / `bg-popover`: Select dropdown content, dialog overlay portal backgrounds

## Component Visual Contracts

### Button
- Variant mapping: `props.color="red"` -> `variant="destructive"`, `props.outline=true` -> `variant="outline"`, default -> `variant="default"`
- Size: shadcn `default` (36px height, 16px horizontal padding, 14px text)
- Icon + label: 8px gap between icon and label text
- Icon-only buttons: Must include `aria-label` derived from `props.ariaLabel` or `props.label`. If neither is provided, use the icon name as a fallback aria-label.
- Disabled state: `opacity-50 cursor-not-allowed` (shadcn default)
- Loading state: Replace icon with `Loader2` spinning at `animate-spin`

### TextInput
- Label above input with 8px (gap-2) vertical spacing
- Input height: 36px (shadcn default `h-9`)
- Border: `border-input` default, `ring-ring` on focus
- Error state: `border-destructive` border, error message in `text-destructive text-xs` below input with 4px top margin
- Placeholder text: `text-muted-foreground`

### SelectInput
- Label above trigger with 8px (gap-2) vertical spacing
- Trigger height: 36px matching TextInput
- Dropdown content: `bg-popover` with `border-border`, 4px border-radius (`--radius`)
- Selected item: `bg-accent` highlight
- Placeholder: `text-muted-foreground` in trigger when no value selected

### Checkbox
- 16px square checkbox (shadcn default)
- 8px gap between checkbox and label
- Checked fill: `bg-primary` with white checkmark
- Label: 14px semibold (weight 600), same line as checkbox (flex row, items-center)

### DataTable
- Table header: `bg-muted` background, `text-muted-foreground` uppercase 12px font-semibold
- Table rows: `border-b border-border` between rows
- Sortable column header: cursor-pointer, chevron icon (12px) right of header text, 4px gap
- Active sort: `text-foreground` (not muted), filled chevron
- Cell text: 14px regular, `text-foreground`
- Row hover: `hover:bg-muted/50` (subtle highlight)

### ModalSurface (Dialog)
- Overlay: `bg-black/80` (shadcn default)
- Content: `bg-card` with `border-border`, max-width 512px (`sm:max-w-lg`), 24px padding
- Close button: X icon in top-right corner, `text-muted-foreground hover:text-foreground`
- Animation: shadcn default fade-in/zoom-in via tw-animate-css

### ConfirmDialog
- Same dialog chrome as ModalSurface
- Title: 20px semibold, `text-foreground`
- Description: 14px regular, `text-muted-foreground`
- Footer: right-aligned buttons with 8px gap
- Destructive confirm: `variant="destructive"`, cancel: `variant="outline"`
- Non-destructive confirm: `variant="default"`, cancel: `variant="outline"`
- Cancel label: server-driven via `props.cancelLabel` (e.g. "Keep Contact", "Go Back"). No hardcoded default -- server must provide both `confirmLabel` and `cancelLabel`.

### ToastSurface
- Position: bottom-right viewport corner, 16px from edges
- Toast card: `bg-card border-border` with shadow-lg, 16px padding, 4px border-radius
- Stack direction: newest on top, 8px gap between toasts
- Auto-dismiss: managed by SDUI surface events (server-driven)
- Close button: X icon, 16px, top-right of toast card
- Variants: default (neutral border), error (`border-destructive` left accent)

### Container
- Card variant: `bg-card border-border rounded-md` with 16px padding
- Plain variant: transparent div, no border, used for layout grouping only

### Grid
- CSS Grid layout using inline `style="grid-template-columns: repeat({cols}, 1fr)"` (NOT dynamic Tailwind classes)
- Gap: 16px (1rem) default between grid items
- Responsive: `md:` breakpoint for column override if `props.mdCols` provided

### Heading
- Semantic h1-h6 tag from `props.level`
- h1/h2: 20px semibold, `text-foreground`
- h3-h6: 16px semibold, `text-foreground`
- No bottom margin (parent layout controls spacing)

### Text
- Renders as `<p>` tag
- 14px regular, `text-foreground`
- Muted variant: `text-muted-foreground` when `props.muted=true`

### SideNav / NavItem / NavGroup
- SideNav: vertical flex column, `bg-sidebar-background`, full height
- NavItem: shadcn Button `variant="ghost"`, full width, left-aligned text
- NavItem active: `bg-sidebar-accent text-sidebar-accent-foreground`
- NavItem icon: 16px, 8px gap before label
- NavGroup: 8px top margin, optional 12px semibold uppercase group label in `text-muted-foreground`

### LoadingSkeleton
- shadcn Skeleton component: `bg-primary/10` with pulse animation
- 3 rows of varying widths (100%, 80%, 60%) with 8px gaps

### Spinner
- SVG spinner, 24px default, `text-primary`, `animate-spin`
- Centered in parent container

### ErrorDisplay
- `AlertCircle` lucide icon in `text-destructive`, 20px
- Error message: 14px, `text-foreground`
- Layout: flex row, 8px gap between icon and text
- Background: `bg-destructive/10`, 8px padding, `rounded-md`

### ConnectionBanner
- Full-width bar at top, `bg-destructive text-primary-foreground`, 8px vertical padding
- Text: 14px semibold, centered
- Visible only when connection is lost

### FallbackComponent (dev-only)
- `border-destructive bg-destructive/10 text-destructive` (replace current hardcoded `border-red-500 bg-red-50 text-red-700`)
- 8px padding, `rounded-md`, monospace font for component type name

### FormScreen
- Back button: shadcn Button `variant="ghost"` with `ArrowLeft` icon
- Form sections: shadcn Card with 16px padding, shadcn Separator between sections
- Action bar: right-aligned, 8px gap between buttons

### TableScreen
- Toolbar: flex row, 8px gap between action buttons
- Action buttons: shadcn Button `variant="outline"` for secondary, `variant="default"` for primary

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Context-dependent (server-driven via `props.label` -- e.g. "Save Contact", "Create Company") |
| Empty state heading | Not in Phase 11 scope (deferred to TABLE-06 in v2) |
| Empty state body | Not in Phase 11 scope |
| Error state (field) | `{field label} is required` / `Invalid {field label}` (server-driven via SDUI protocol) |
| Error state (connection) | `Connection lost. Reconnecting...` |
| Error state (component) | `Something went wrong displaying this component.` |
| Destructive confirmation (ConfirmDialog) | Title: server-driven `props.title` (e.g. "Delete Contact?") / Body: server-driven `props.message` / Confirm: server-driven `props.confirmLabel` (e.g. "Delete") / Cancel: server-driven `props.cancelLabel` (e.g. "Keep Contact") |
| Toast default | Server-driven `props.message` |
| Fallback icon tooltip | `Unknown icon: {name}` (dev-only, shown via `title` attribute on CircleHelp fallback) |

Note: This is an SDUI application. Almost all user-facing copy is server-driven via component `props`. The frontend hardcodes only structural copy (connection errors, fallback states). The server is the source of truth for all business-domain copy. The ConfirmDialog cancel label is server-driven (`props.cancelLabel`) -- no hardcoded "Cancel" default.

## Interaction Contracts

| Component | Trigger | Behavior |
|-----------|---------|----------|
| Button | click | Dispatch `action` via `sendAction()`. Disable during pending (if `props.disabled`). |
| TextInput | input/blur | Update bound value via `setData(surface, bind, value)`. Dispatch blur action if configured. |
| SelectInput | value change | Update bound value via `setData(surface, bind, newValue)` through `onValueChange` callback. |
| Checkbox | checked change | Update bound value via `setData(surface, bind, checked)` through `onCheckedChange` callback. |
| Form | submit | Dispatch form `action` via `sendAction()`. Prevent default form submission. |
| ModalSurface | open/close | `open` derived from surface tree existence. Close dispatches `close-modal` action via `onOpenChange`. Never let Dialog manage its own state. |
| ConfirmDialog | confirm/cancel | Confirm dispatches `action`. Cancel closes dialog. |
| ToastSurface | dismiss | Remove toast from component state. Auto-dismiss managed by SDUI surface events. |
| DataTable | header click | Dispatch sort action to server. Server responds with re-ordered data. |
| NavItem | click | Dispatch navigation action via `sendAction()`. |
| SideNav | -- | Passive container, renders NavGroup/NavItem children. |
