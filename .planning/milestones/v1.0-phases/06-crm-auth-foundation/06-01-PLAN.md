**6. Create `handlers/auth.rs`** with:

- `#[derive(Deserialize)] pub struct LoginRequest { pub username: String, pub password: String }`
- `pub async fn handle_login(State(state): State<Arc<AppState>>, jar: CookieJar, Json(req): Json<LoginRequest>) -> Result<(CookieJar, Json<serde_json::Value>), StatusCode>` that:
  1. Looks up user by email: `user::Entity::find().filter(user::Column::UserEmail.eq(&req.username)).one(&*state.db).await`
  2. Returns `StatusCode::UNAUTHORIZED` if not found
  3. Verifies password with `tokio::task::spawn_blocking(move || bcrypt::verify(password, &hash))` -- returns UNAUTHORIZED if invalid
  4. Creates session token: `uuid::Uuid::new_v4().to_string()`
  5. Inserts session row into `session` table (from marionette db.rs) with: `session_token = token`, `session_user = Some(user.user_id)`, `session_roles = serde_json::json!(vec![user.user_role]).to_string()`, `session_expires` = now + 24 hours (use chrono `Utc::now() + Duration::hours(24)` formatted as ISO 8601)
  6. Updates `user_last_login` to current timestamp
  7. Builds cookie: name `"marionette_session"`, path `/`, http_only true, same_site Lax, max_age 24 hours. Use `axum_extra::extract::cookie::{Cookie, CookieJar, SameSite}` and `cookie::time::Duration` for max_age.
  8. Returns `(jar.add(cookie), Json(json!({"ok": true})))`

- `pub async fn handle_logout(State(state): State<Arc<AppState>>, jar: CookieJar) -> (CookieJar, StatusCode)` that:
  1. Gets cookie `"marionette_session"` from jar
  2. If present, deletes the session row from DB
  3. Returns jar with cookie removed and `StatusCode::OK`
