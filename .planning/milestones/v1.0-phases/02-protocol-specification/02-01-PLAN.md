**1. Create `spec/schemas/message.yaml`** with these exact top-level definitions:

- `ProtocolMessage`: oneOf union of all 6 message types with discriminator on `type` field:
  ```yaml
  ProtocolMessage:
    description: Tagged union of all protocol message types
    oneOf:
      - $ref: "#/HelloMessage"
      - $ref: "#/RenderMessage"
      - $ref: "#/PatchMessage"
      - $ref: "#/ActionMessage"
      - $ref: "#/EventMessage"
      - $ref: "#/ErrorMessage"
    discriminator:
      propertyName: type
      mapping:
        hello: "#/HelloMessage"
        render: "#/RenderMessage"
        patch: "#/PatchMessage"
        action: "#/ActionMessage"
        event: "#/EventMessage"
        error: "#/ErrorMessage"
  ```

- `HelloMessage`: type object, required [type, version], additionalProperties false
  - type: string, const "hello"
  - version: string, description "Protocol version (semver)", example "1.0.0"

- `RenderMessage`: type object, required [type, surface, root, nodes, data], additionalProperties false
  - type: string, const "render"
  - id: $ref "common.yaml#/MessageId"
  - surface: $ref "common.yaml#/Surface"
  - root: string, description "ID of the root node in the adjacency list"
  - nodes: type object, additionalProperties $ref "component.yaml#/Component", description "Flat map of node ID to component definition"
  - data: type object, description "Application state that components bind to"

- `PatchMessage`: type object, required [type, patch], additionalProperties false
  - type: string, const "patch"
  - id: $ref "common.yaml#/MessageId"
  - patch: type array, items $ref "data.yaml#/PatchOperation", description "Array of patch operations to apply"

- `ActionMessage`: type object, required [type, name], additionalProperties false
  - type: string, const "action"
  - id: $ref "common.yaml#/MessageId"
  - name: string, description "Action identifier"
  - source: string, description "Component ID that triggered the action"
  - payload: type object, additionalProperties true, description "Action-specific data"
  - optimistic: type object with required [patch] property, where patch is array of $ref "data.yaml#/PatchOperation", description "Patches to apply immediately (rolled back on error)"

- `EventMessage`: type object, required [type, name], additionalProperties false
  - type: string, const "event"
  - id: $ref "common.yaml#/MessageId"
  - name: string, description "Event identifier"
  - surface: $ref "common.yaml#/Surface" (optional -- which surface the event targets)
  - hint: type object, additionalProperties true, description "Event-specific metadata"

- `ErrorMessage`: type object, required [type, errors], additionalProperties false
  - type: string, const "error"
  - id: $ref "common.yaml#/MessageId"
  - errors: type array, items $ref "data.yaml#/ValidationError"

Every message variant MUST have `type` as required with a `const` value -- this is critical for the discriminator to work.

**2. Create `spec/openapi.yaml`** as entry point:
```yaml
openapi: "3.1.0"
info:
  title: OpenSDUI Protocol
  version: "1.0.0"
  description: |
    Server-Driven UI protocol specification.
    All communication occurs over a single WebSocket connection at /ws.
    See spec/PROTOCOL.md for transport details and worked examples.
  license:
    name: MIT

paths: {}

webhooks:
  onMessage:
    post:
      summary: WebSocket message (bidirectional)
      description: |
        All messages (both directions) use the ProtocolMessage envelope.
        This webhook entry documents the message schema;
        actual transport is WebSocket at /ws.
      requestBody:
        content:
          application/json:
            schema:
              $ref: "#/components/schemas/ProtocolMessage"
      responses:
        "200":
          description: Message processed

components:
  schemas:
    ProtocolMessage:
      $ref: "schemas/message.yaml#/ProtocolMessage"
    HelloMessage:
      $ref: "schemas/message.yaml#/HelloMessage"
    RenderMessage:
      $ref: "schemas/message.yaml#/RenderMessage"
    PatchMessage:
      $ref: "schemas/message.yaml#/PatchMessage"
    ActionMessage:
      $ref: "schemas/message.yaml#/ActionMessage"
    EventMessage:
      $ref: "schemas/message.yaml#/EventMessage"
    ErrorMessage:
      $ref: "schemas/message.yaml#/ErrorMessage"
    Component:
      $ref: "schemas/component.yaml#/Component"
    ComponentAction:
      $ref: "schemas/component.yaml#/ComponentAction"
    PatchOperation:
      $ref: "schemas/data.yaml#/PatchOperation"
    KeyedCollection:
      $ref: "schemas/data.yaml#/KeyedCollection"
    ValidationError:
      $ref: "schemas/data.yaml#/ValidationError"
    Surface:
      $ref: "schemas/common.yaml#/Surface"
    JsonPointer:
      $ref: "schemas/common.yaml#/JsonPointer"
    MessageId:
      $ref: "schemas/common.yaml#/MessageId"
```

Ensure all `$ref` paths are correct: from openapi.yaml to schemas/ use `schemas/filename.yaml#/TypeName`. Within schemas/ files, cross-file refs use `filename.yaml#/TypeName`.
