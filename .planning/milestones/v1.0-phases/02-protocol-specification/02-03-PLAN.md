**1. `spec/examples/hello-handshake.yaml`:**
```yaml
# Server hello message sent on WebSocket connect
type: hello
version: "1.0.0"
```

**2. `spec/examples/render-contact-list.yaml`:**
A complete RenderMessage showing a contact list page with adjacency list. Must include:
- surface: "main"
- root pointing to a container node
- nodes map with: container, heading, add-button, data-table (at least 4 nodes demonstrating adjacency list)
- data object with keyed collection of contacts (at least 2 entries), plus an order array
- data-table node with bind to `/contacts`, props with columns array, keyField
- At least one node with an action (ComponentAction)

**3. `spec/examples/patch-update-field.yaml`:**
A PatchMessage updating a contact's email and a loading state:
```yaml
type: patch
id: "msg-r7x9"
patch:
  - path: "/contacts/c-101/contact_email"
    value: "alice.new@example.com"
  - path: "/ui/saving"
    value: false
```

**4. `spec/examples/action-submit-form.yaml`:**
An ActionMessage with optimistic update (core protocol feature):
```yaml
type: action
id: "msg-f3k8"
name: "save-contact"
source: "save-btn"
payload:
  contact_name: "Alice Johnson"
  contact_email: "alice@example.com"
  contact_company: "comp-42"
optimistic:
  patch:
    - path: "/ui/saving"
      value: true
```

**5. `spec/examples/event-close-modal.yaml`:**
An EventMessage closing a modal surface:
```yaml
type: event
name: "close"
surface: "modal"
```

**6. `spec/examples/error-validation.yaml`:**
An ErrorMessage with field-level errors:
```yaml
type: error
id: "msg-f3k8"
errors:
  - path: "/form/data/contact_email"
    message: "Email address is already registered"
  - path: "/form/data/contact_name"
    message: "Name must be between 2 and 100 characters"
```

Each file MUST have a YAML comment at the top explaining what it demonstrates. Ensure all JSON Pointer paths start with `/`. Ensure all required fields per schema are present.
