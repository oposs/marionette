**Icon-cell composition choice (CAT-05 — LOCKED by UI-SPEC §Resolutions line 844):**

UI-SPEC line 844 resolves "CAT-05 icon-cell affordance" to **"Plain Container with icon + label"** — Buttons-without-action are confusing; the catalog is a display, not interactive. We therefore do NOT use `Button(size=icon, variant=outline)` for icon cells. The PATTERNS.md §CAT-05 lines 366-391 snippet pre-dated UI-SPEC resolution and shows the Button form — it is SUPERSEDED by UI-SPEC §Resolutions line 844. The catalog executor MUST use the Container-with-icon composition described below.

**Minimum necessary wiring** (justification for why one primitive gains one optional prop — see Task 0):

No existing Svelte primitive renders a standalone Lucide icon today. `Button.svelte` and `NavItem.svelte` both render `getIcon(props.icon)` but are both click-target affordances; using either for CAT-05 cells reintroduces the very "button without action" anti-pattern UI-SPEC §Resolutions forbids. There are two alternatives: (a) invent a brand-new `<Icon>` primitive (prohibited by the revision instructions — scope creep), or (b) extend the existing `<Container>` primitive with one optional `icon` prop that renders `getIcon(props.icon)` before children when present. Option (b) is a ~5-line surgical addition to an already-registered primitive, carries no new surface area on the frontend, and matches the NavItem pattern (lines 27-29 + 51-53 of NavItem.svelte). Chosen composition: option (b).

**Container primitive extension** (Task 0 — PRE-CAT-05-render step):
- Rust: add `#[builder(optional)] pub icon: Option<String>` to `backend/crates/marionette/src/builders/container.rs` `Container` struct. The derive macro auto-generates `.icon(impl Into<String>)`.
- Svelte: add one optional `props.icon` branch to `frontend/src/lib/components/layout/Container.svelte` mirroring NavItem.svelte lines 7 + 27-29 + 51-53. Icon renders before children, size-4 default, `aria-hidden="true"` (since a text label always accompanies — a11y covered by the sibling Text node).

```rust

    .id(format!("catalog-typo-icon-cell-{name}"))
    .class(ICON_CELL_CLASS)               // "flex flex-col items-center gap-1 p-2 rounded border"
```
