Create `handlers/contact.rs` following the user.rs CRUD pattern with these FK-specific additions:

**Imports** (matching user.rs style plus FK additions):
```rust
use std::collections::HashMap;
use sea_orm::{ActiveModelTrait, ColumnTrait, EntityTrait, QueryFilter, QueryOrder};
use serde::Deserialize;
use marionette::builders::standard::{Button, Container, DataTable, Form, Heading, Select, SelectOption, TableColumn, TextInput};
use marionette::error::{ActionError, ActionResult};
use marionette::extractors::{Db, FromHandlerContext, HandlerContext, Payload, Session};
use marionette_protocol::{ComponentAction, ProtocolMessage, RenderMessage};
use crate::entities::{company, contact};
```

**render_contact_list** (private helper):
- Query contacts with joined company: `contact::Entity::find().find_also_related(company::Entity).order_by_asc(contact::Column::ContactName).all(&*db.0).await`
- For each (contact, option_company) tuple, build row JSON:
  ```json
  {
    "id": contact.contact_id,
    "name": contact.contact_name,
    "email": contact.contact_email,
    "phone": contact.contact_phone.as_deref().unwrap_or("-"),
    "company": company.map(|c| c.company_name.as_str()).unwrap_or("-"),
    "created": contact.contact_created_at,
    "actions": [
      { "label": "Edit", "action": { "type": "click", "name": "contact_edit", "payload": { "contact_id": contact.contact_id } } },
      { "label": "Delete", "action": { "type": "click", "name": "contact_delete", "payload": { "contact_id": contact.contact_id } } }
    ]
  }
  ```
- DataTable columns: name (sortable), email (sortable), phone (sortable), company (sortable, key "company", label "Company"), created (sortable)
- Table id: "contact-table", bind: "/contacts"
- Heading: "Contact Management", id: "contact-heading"
- New button: "New Contact", id: "btn-new-contact", action: click "contact_new"
- Container root id: "contact-list-root"
- Return RenderMessage on surface "main"

**handle_contact_list**: Delegate to `render_contact_list(&ctx).await`

**handle_contact_form**:
- Try to extract `ContactIdPayload { contact_id: i32 }` -- present = edit, absent = create
- Edit mode: find contact by ID, populate form data:
  ```json
  {"contactForm": {"id": N, "name": "...", "email": "...", "phone": "...", "title": "...", "company": "company_id_as_string_or_empty"}}
  ```
  For the company field value: `contact.contact_company.map(|id| id.to_string()).unwrap_or_default()`
- Create mode: empty form data with all fields as empty strings, id as null, company as ""
- **Company select dropdown**: Query all companies ordered by name. Build options:
  - First option: `SelectOption { value: "".into(), label: "No Company".into() }`
  - Then for each company: `SelectOption { value: co.company_id.to_string(), label: co.company_name.clone() }`
  - `Select::new("Company", options).id("contact-form-company").bind("/contactForm/company")`
- Form fields in order: name (TextInput), email (TextInput), phone (TextInput), title (TextInput), company (Select), save button, cancel button
  - name: id "contact-form-name", bind "/contactForm/name"
  - email: id "contact-form-email", bind "/contactForm/email"
  - phone: id "contact-form-phone", bind "/contactForm/phone"
  - title: id "contact-form-title", bind "/contactForm/title"
  - save: id "contact-form-save", action submit "contact_save"
  - cancel: id "contact-form-cancel", action click "contact_list"
- Form id: "contact-form", container root: "contact-form-root"
- Heading: "Edit Contact" or "New Contact"

**handle_contact_save**:
- Payload struct: `ContactSavePayload { id: Option<i32>, name: String, email: String, phone: Option<String>, title: Option<String>, company: Option<String> }`
- Validation:
  - name empty -> `ActionError::BadPayload("Contact name is required")`
  - email empty -> `ActionError::BadPayload("Email is required")`
  - email does not contain '@' -> `ActionError::BadPayload("Invalid email format")`
- Parse company FK: `let company_id: Option<i32> = data.company.as_deref().and_then(|s| if s.is_empty() { None } else { s.parse().ok() });`
- Create mode: Insert `contact::ActiveModel` with Set(...) for all fields, NotSet for timestamps (DB defaults). Record audit.
- Edit mode: Find by ID, build old_json, update all fields including `contact_updated_at: Set(now_sqlite())` (reuse the timestamp helper from company.rs or define locally). Compute changes, record audit.
- After save: `render_contact_list(&ctx).await`

**handle_contact_delete**:
- Extract ContactIdPayload, find contact, build deleted_json
- Delete contact
- Record audit with table "contact"
- Re-render list

**handlers/mod.rs** -- Add `pub mod contact;`

For the `now_sqlite()` helper, either:
- Import it from company.rs if made pub (check if Plan 02 made it pub)
- Or define a local copy: `fn now_sqlite() -> String { ... }` using `time::OffsetDateTime::now_utc()` formatted as "YYYY-MM-DD HH:MM:SS"
- Best option: If company.rs has it as `pub(crate) fn now_sqlite()`, use `crate::handlers::company::now_sqlite()`. Otherwise define locally.
