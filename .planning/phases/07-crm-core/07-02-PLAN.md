Create `handlers/company.rs` following the exact pattern of `handlers/user.rs`. Four public handler functions:

**render_company_list** (private helper, called by list and after mutations):
- Query all companies: `company::Entity::find().all(&*db.0).await`
- For each company, count linked contacts: query `contact::Entity::find().filter(contact::Column::ContactCompany.eq(company.company_id)).count(&*db.0).await`. NOTE: This is a simple count per company which is fine at demo scale. Do NOT do N+1 in production, but for a demo CRM this is acceptable and avoids complex grouped queries.
- Build a `Heading::new("Company Management").id("company-heading")`
- Build a `Button::new("New Company").id("btn-new-company").action(ComponentAction::click("company_new"))`
- Build a `DataTable` with columns: name (sortable), website (sortable), contactCount (sortable, key "contactCount", label "Contacts"), created (sortable, key "created", label "Created")
  - Table id: "company-table", bind: "/companies"
- Per-row actions column with Edit (action: click "company_edit" payload {company_id}) and Delete (action: click "company_delete" payload {company_id})
- Data JSON: `{ "companies": [ { "id": ..., "name": ..., "website": ..., "contactCount": N, "created": ..., "actions": [...] } ] }`
- Wrap in Container with id "company-list-root"
- Return RenderMessage on surface "main" with root "company-list-root"
- Default sort: name ascending. Use `.order_by_asc(company::Column::CompanyName)` on the query.
- For empty website, display "-"

**handle_company_list**: Delegate to `render_company_list(&ctx).await`

**handle_company_form**:
- Try to extract `CompanyIdPayload { company_id: i32 }` -- if present, edit mode; if absent, create mode
- Edit mode: find company by ID, populate form data `{"companyForm": {"id": N, "name": "...", "website": "...", "address": "..."}}`
- Create mode: empty form data `{"companyForm": {"id": null, "name": "", "website": "", "address": ""}}`
- Build form components:
  - `Heading::new(form_title).id("company-form-heading")` where form_title is "Edit Company" or "New Company"
  - `TextInput::new("Name").id("company-form-name").bind("/companyForm/name")`
  - `TextInput::new("Website").id("company-form-website").bind("/companyForm/website")`
  - `TextInput::new("Address").id("company-form-address").bind("/companyForm/address")`
  - `Button::new("Save").id("company-form-save").action(ComponentAction::submit("company_save"))`
  - `Button::new("Cancel").id("company-form-cancel").action(ComponentAction::click("company_list"))`
  - Wrap inputs in `Form::new().id("company-form").children([...]).build_with_children()`
  - Wrap heading + form in `Container::new().id("company-form-root").children([...]).build_with_children()`
- Return RenderMessage on surface "main" with root "company-form-root"

**handle_company_save**:
- Deserialize payload: `CompanySavePayload { id: Option<i32>, name: String, website: Option<String>, address: Option<String> }`
- Validate: name must not be empty (return `ActionError::BadPayload("Company name is required")`)
- Create mode (id is None): Insert new `company::ActiveModel` with `Set(...)` fields. Set `company_created_at` and `company_updated_at` to NotSet (use DB defaults). Call `record_audit(db, caller_id, "company", inserted.company_id, "create", company_json)`.
- Edit mode (id is Some): Find by ID, build old_json, update fields including `company_updated_at` set to current datetime (`chrono::Utc::now().format("%Y-%m-%d %H:%M:%S").to_string()` -- but since the project uses the `time` crate, check what's available. Actually, just use a simple string: use `sea_orm::prelude::DateTimeUtc` or format manually. Simplest: set `company_updated_at: Set(chrono... )`. WAIT -- the project does NOT use chrono. Look at how user.rs handles this -- it does NOT update timestamps because user entity has no updated_at. For company, explicitly set updated_at. Use the approach from RESEARCH.md: get current time as string. Since no chrono in deps, use a raw SQL approach or add a simple helper. Simplest: `Set(format!("{}", time::OffsetDateTime::now_utc().format(&time::format_description::well_known::Rfc3339).unwrap()))`. But actually the `time` crate IS in workspace deps (added Phase 6). Use `time::OffsetDateTime::now_utc()` and format to match SQLite datetime format `YYYY-MM-DD HH:MM:SS`. Format string: `[year]-[month]-[day] [hour]:[minute]:[second]`. Compute changes via `compute_changes(&old_json, &new_json)`. Call `record_audit`.
- After save, re-render list: `render_company_list(&ctx).await`

**handle_company_delete**:
- Extract `CompanyIdPayload { company_id }`
- Find company by ID
- Build deleted_json for audit
- Delete the company (ON DELETE SET NULL handles contact FK)
- Call `record_audit(db, caller_id, "company", deleted_id, "delete", deleted_json)`
- Re-render list: `render_company_list(&ctx).await`
