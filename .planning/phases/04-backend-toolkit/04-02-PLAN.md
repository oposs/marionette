2. Create backend/crates/marionette-macros/src/component_builder.rs:
   The #[derive(ComponentBuilder)] macro with #[component(type = "text-input")] attribute:
   - Uses darling to parse #[component(type = "...")] from the struct
   - Uses darling to parse #[builder(optional)] on fields
   - Generates a builder struct named {StructName}Builder
   - Fields WITHOUT #[builder(optional)] become required constructor parameters in StructName::new(field1, field2, ...)
   - Fields WITH #[builder(optional)] become optional setter methods on the builder
   - Builder always gets these methods regardless of struct fields:
     - fn bind(mut self, path: impl Into<String>) -> Self
     - fn action(mut self, action: marionette_protocol::ComponentAction) -> Self
     - fn visible(mut self, path: impl Into<String>) -> Self
     - fn child(mut self, child: (String, marionette_protocol::Component)) -> Self  (appends to internal children vec AND collects the node)
     - fn children(mut self, children: Vec<(String, marionette_protocol::Component)>) -> Self (appends all)
     - fn id(mut self, id: impl Into<String>) -> Self (override auto-generated ID)
   - fn build(self) -> (String, marionette_protocol::Component):
     - Collects all required + optional fields into a serde_json::Value for props (only non-None optional fields included)
     - Creates Component { type: component_type_string, props, children: child_ids, bind, action, visible }
     - Returns (node_id, component) where node_id is either user-set or "{component_type}-{uuid}"
     - ALSO returns collected child nodes somehow -- use a method fn build_with_children(self) -> Vec<(String, Component)> that returns self node + all child nodes flattened
   - Use fully qualified paths in generated code: ::std::string::String, ::serde_json::json!, ::marionette_protocol::Component, etc. (edition 2024 compatibility per research pitfall #5)
