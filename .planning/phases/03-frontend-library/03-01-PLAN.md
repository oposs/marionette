1. Create `frontend/src/lib/transport/messages.ts` with all TypeScript interfaces matching protocol schemas exactly:
   - `HelloMessage`: `{ type: 'hello'; version: string }`
   - `RenderMessage`: `{ type: 'render'; id?: string; surface: string; root: string; nodes: Record<string, ComponentNode>; data: Record<string, unknown> }`
   - `PatchMessage`: `{ type: 'patch'; id?: string; patch: PatchOperation[] }`
   - `ActionMessage`: `{ type: 'action'; id?: string; name: string; source?: string; payload?: Record<string, unknown>; optimistic?: { patch: PatchOperation[] } }`
   - `EventMessage`: `{ type: 'event'; id?: string; name: string; surface?: string; hint?: Record<string, unknown> }`
   - `ErrorMessage`: `{ type: 'error'; id?: string; errors: ValidationError[] }`
   - `ProtocolMessage`: discriminated union of all 6
   - `ComponentNode`: `{ type: string; props?: Record<string, unknown>; children?: string[]; bind?: string; action?: ComponentAction; visible?: string }`
   - `ComponentAction`: `{ type: string; name?: string; target?: string; idPath?: string; [key: string]: unknown }`
   - `PatchOperation`: `{ path: string; value: unknown }`
   - `ValidationError`: `{ path?: string; message: string }`
   - `Surface` type: `'main' | 'sidebar' | 'modal' | 'toast'`

2. Create `frontend/src/lib/store/pointer.ts` (plain .ts -- no runes needed):
   - `import { JsonPointer } from 'json-ptr'`
   - `resolvePointer(obj: Record<string, unknown>, pointer: string): unknown` -- uses `JsonPointer.get(obj, pointer)`
   - `setAtPointer(obj: Record<string, unknown>, pointer: string, value: unknown, create: boolean = true): void` -- uses `JsonPointer.set(obj, pointer, value, create)`. If value is `null`, parse pointer to get parent path and key, then `delete parent[key]`.
   - Handle empty pointer `""` as root reference

3. Create `frontend/src/lib/store/dirty.svelte.ts`:
   - `const dirtyPaths = new Set<string>()` (no $state needed -- this is a simple Set used synchronously)
   - `const pendingPatches = new Map<string, PatchOperation[]>()`
   - `markDirty(path: string): void` -- adds path to dirtyPaths
   - `clearDirty(path: string, applyFn: (op: PatchOperation) => void): void` -- removes from dirtyPaths, applies queued patches via applyFn callback, deletes from pendingPatches
   - `isDirty(path: string): boolean` -- returns true if path or any parent path is in dirtyPaths (iterate dirtyPaths, check `path === dirty || path.startsWith(dirty + '/')`)
   - `queuePatch(path: string, op: PatchOperation): void` -- appends to pendingPatches map
   - `resetDirty(): void` -- clears both sets

4. Create `frontend/src/lib/store/data.svelte.ts`:
   - `const surfaces: Record<string, { data: Record<string, unknown> }> = $state({})`
   - `getStore(surface: string)` -- returns surfaces[surface], creating `{ data: {} }` if missing
   - `getData(surface: string, pointer: string): unknown` -- calls `resolvePointer(getStore(surface).data, pointer)`
   - `setData(surface: string, pointer: string, value: unknown): void` -- calls `setAtPointer(getStore(surface).data, pointer, value)`
   - `setFullState(surface: string, data: Record<string, unknown>): void` -- replaces `getStore(surface).data` with shallow copy via `Object.assign(getStore(surface).data, {}); Object.assign(getStore(surface).data, data)` (must mutate, not reassign, for $state reactivity)
   - Actually for setFullState: clear all keys from existing data object first (`for (const key of Object.keys(store.data)) delete store.data[key]`), then assign new keys
   - `applyPatch(surface: string, operations: PatchOperation[]): void` -- iterates operations; if `isDirty(op.path)`, calls `queuePatch(op.path, op)`; otherwise calls `setData(surface, op.path, op.value)`
   - `resetStore(surface: string): void` -- deletes surfaces[surface]
   - Import isDirty and queuePatch from dirty.svelte.ts
   - Import resolvePointer, setAtPointer from pointer.ts

5. Create `frontend/src/lib/store/optimistic.svelte.ts`:
   - `interface OptimisticEntry { surface: string; snapshots: Map<string, unknown> }`
   - `const pending = new Map<string, OptimisticEntry>()`
   - `applyOptimistic(correlationId: string, surface: string, operations: PatchOperation[]): void` -- for each op, snapshot `getData(surface, op.path)`, then `setData(surface, op.path, op.value)`. Store entry in pending.
   - `confirmOptimistic(correlationId: string): void` -- `pending.delete(correlationId)`
   - `rollbackOptimistic(correlationId: string): void` -- if entry exists, restore each snapshot via `setData`, then delete from pending
   - Import getData, setData from data.svelte.ts

6. Write tests FIRST (RED), then implement (GREEN):
   - `data.svelte.test.ts`: Test all behaviors listed above. Import from `$lib/store/data.svelte` and `$lib/store/dirty.svelte`. Use `beforeEach` to call `resetStore` and `resetDirty`.
   - `dirty.svelte.test.ts`: Test all dirty behaviors. Use mock applyFn callback to verify patch application on clearDirty.
   - `optimistic.svelte.test.ts`: Test snapshot/restore/confirm. Set initial data, apply optimistic, verify changed, rollback, verify restored.
