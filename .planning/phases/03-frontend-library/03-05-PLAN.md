<!-- Standard Marionette component interface -->
Every component receives via $props():
  props: Record<string, unknown>
  bind?: string           -- JSON Pointer
  action?: ComponentAction
  surface: string
  children?: Snippet

<!-- Store API -->
getData(surface, pointer): unknown
setData(surface, pointer, value): void
markDirty(path): void
clearDirty(path, applyFn): void
sendAction(name, payload?, source?, optimistic?): void

<!-- Flowbite Svelte components to wrap -->
Form: Input, Select, Checkbox, Button, Label, Helper
Table: Table, TableHead, TableBody, TableHeadCell, TableBodyRow, TableBodyCell
Popup: Modal, Toast
Icons: ChevronUpOutline, ChevronDownOutline

<!-- From 03-UI-SPEC.md -->
Virtual Scroll Table:
  Row height: 48px fixed
  Visible buffer: 3 rows above and below viewport
  Chunk size: 50 rows per request
  Prefetch trigger: within 2 chunks of unloaded region
  Sort indicator: ChevronUp/ChevronDown in header cells
  Sortable header: cursor-pointer, hover:bg-gray-100

Modal:
  Sizes: sm=max-w-md, md=max-w-lg, lg=max-w-2xl
  Close on backdrop click: yes (send close-modal action)
  Close on Escape: yes (send close-modal action)

Toast:
  Position: fixed top-right, 16px inset, z-60
  Stack: top-to-bottom, newest on top, gap 8px
  Auto-dismiss: 5000ms default (overridable via duration field)
  Animation: fade-in/out 200ms
  Variants: success=green, error=red, warning=yellow, info=blue

1. Create `frontend/src/lib/components/table/DataTable.svelte`:
   - Import `Table`, `TableHead`, `TableBody`, `TableHeadCell`, `TableBodyRow`, `TableBodyCell` from `flowbite-svelte`
   - Import `ChevronUpOutline`, `ChevronDownOutline` from `flowbite-svelte-icons`
   - Import `getData` from `$lib/store/data.svelte`
   - Import `sendAction` from `$lib/transport/dispatcher`

   Virtual scroll implementation (custom, not @tanstack -- simpler and avoids Svelte 5 compat issues):
   - Constants: `ROW_HEIGHT = 48`, `BUFFER = 3`, `CHUNK_SIZE = 50`
   - Props mapping:
     - `props.columns` -> array of `{ key: string, label: string, sortable?: boolean }` column definitions
     - `props.totalRows` -> total number of rows (from backend)
     - `props.rowIdKey` -> key field in row data for stable identity (default 'id')
   - Data: read rows from `bind` pointer -- expected to be a Record<string, Record<string, unknown>> (keyed collection)
   - Derive rows array: `Object.entries(getData(surface, bind) as Record<string, unknown> ?? {})`
   - Virtual scroll state (`$state`):
     - `scrollTop = 0`
     - `containerHeight = 0` (measured via bind:clientHeight on scroll container)
   - Computed:
     - `totalHeight = props.totalRows * ROW_HEIGHT`
     - `visibleStart = Math.max(0, Math.floor(scrollTop / ROW_HEIGHT) - BUFFER)`
     - `visibleEnd = Math.min(props.totalRows, Math.ceil((scrollTop + containerHeight) / ROW_HEIGHT) + BUFFER)`
     - `visibleRows = rows.slice(visibleStart, visibleEnd)` (from the keyed data)
     - `offsetY = visibleStart * ROW_HEIGHT` (translateY for visible rows)
   - Prefetch: when `visibleEnd` is within `CHUNK_SIZE * 2` of loaded data boundary, dispatch `sendAction('fetch-rows', { offset: loadedEnd, limit: CHUNK_SIZE })`
   - Sort: on header click for sortable columns, dispatch `sendAction('sort', { column: col.key, direction: nextDirection })`. Track current sort column and direction in `$state`. Toggle asc/desc/none.
   - Sort indicators: `{#if sortColumn === col.key}{#if sortDir === 'asc'}<ChevronUpOutline class="w-4 h-4 inline" />{:else}<ChevronDownOutline class="w-4 h-4 inline" />{/if}{/if}`
   - Sortable header styling: `class="cursor-pointer hover:bg-gray-100"` on sortable `<TableHeadCell>`
   - Scroll container: `<div class="overflow-y-auto" style="height: 100%;" onscroll={(e) => scrollTop = e.currentTarget.scrollTop} bind:clientHeight={containerHeight}>`
   - Inside: `<div style="height: {totalHeight}px; position: relative;">` with visible rows at `transform: translateY({offsetY}px)`
   - Each row: `<TableBodyRow style="height: {ROW_HEIGHT}px">` with cells from column keys

   Row click action: if `action` prop set, clicking a row dispatches `sendAction(action.name ?? 'select-row', { id: rowId }, action.target)`

2. Create `frontend/src/lib/components/popup/ModalSurface.svelte`:

   - Import `NodeRenderer` from `$lib/components/core/NodeRenderer.svelte`
   - Import `sendAction` from `$lib/transport/dispatcher`
   - Derive tree from `getSurfaceTree('modal')`
   - Show modal when tree is not undefined
   - Size mapping from tree.nodes[tree.root].props.size: `sm` -> `'sm'`, `md` -> `'md'`, `lg` -> `'lg'` (Flowbite Modal size prop)
   - On close (backdrop click or Escape): `sendAction('close-modal')`
   - Content: `<NodeRenderer nodeId={tree.root} nodes={tree.nodes} surface="modal" />`
   - Focus management: Flowbite Modal handles focus trapping automatically

3. Create `frontend/src/lib/components/popup/ToastSurface.svelte`:
   - Import `Toast` from `flowbite-svelte`
   - Manage a `$state` toast stack: `let toasts: Array<{ id: string, severity: string, message: string, duration: number }> = $state([])`
   - Export `addToast(event: EventMessage)`: push to stack with `id: crypto.randomUUID()`, extract severity from `event.hint?.severity ?? 'info'`, message from `event.hint?.message ?? event.name`, duration from `event.hint?.duration ?? 5000`
   - Auto-dismiss: `setTimeout(() => removeToast(id), duration)` on add
   - Remove: filter out by id
   - Position: `<div class="fixed top-4 right-4 z-[60] flex flex-col gap-2" style="max-width: 384px;">`
   - Each toast: `<Toast color={severityToColor(severity)} transition="slide">`
   - Severity to Flowbite color: success='green', error='red', warning='yellow', info='blue' (default)
   - Animation: Flowbite Toast has built-in transition support; if not sufficient, use Svelte `transition:fly` from right

4. Create `frontend/src/lib/components/popup/ConfirmDialog.svelte`:

   - Props: `props.title` (heading), `props.message` (body text), `props.confirmLabel` (default "Confirm"), `props.cancelLabel` (default "Cancel"), `props.destructive` (boolean, makes confirm button red)
   - Two buttons: Confirm dispatches `action` (from component action prop), Cancel dispatches `sendAction('close-modal')`
