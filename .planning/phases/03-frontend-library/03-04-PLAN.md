  action?: ComponentAction        -- action to dispatch on interaction
  surface: string                 -- which surface this renders in

getData(surface: string, pointer: string): unknown
setData(surface: string, pointer: string, value: unknown): void

<!-- Action dispatch (from Plan 02) -->

1. Create `frontend/src/lib/components/layout/Container.svelte`:
   - Accept standard Marionette props + children
   - Import `Card` from `flowbite-svelte`
   - Render: `<Card class={props.class ?? ''}>{@render children?.()}</Card>`
   - Props: `props.padding` (default 'md' -> 'p-4'), `props.class` for additional classes

2. Create `frontend/src/lib/components/layout/Grid.svelte`:
   - Accept standard Marionette props + children
   - Render: `<div class="grid {colsClass} {gapClass}">{@render children?.()}</div>`
   - Props mapping:
     - `props.cols` (number, default 1) -> `grid-cols-{n}` (Tailwind)
     - `props.gap` (string, default 'md') -> gap class: sm='gap-2', md='gap-4', lg='gap-6', xl='gap-8'
     - `props.flow` ('row' | 'col', default 'row')
   - If `props.flex` is true, use `flex` instead of `grid` with `flex-wrap`

3. Create `frontend/src/lib/components/layout/Heading.svelte`:
   - Accept standard Marionette props
   - Import `getData` from `$lib/store/data.svelte`
   - Text content: if `bind`, use `getData(surface, bind) as string`; else `props.text`
   - Level: `props.level` (1-6, default 2)
   - Render the appropriate heading element:
     - Level 1: `<h1 class="text-[28px] font-semibold leading-[1.2]">{text}</h1>` (Display from UI-SPEC)
     - Level 2: `<h2 class="text-xl font-semibold leading-[1.2]">{text}</h2>` (Heading from UI-SPEC)
     - Level 3-6: `<h3-h6 class="text-base font-semibold leading-[1.2]">{text}</h3-h6>`
   - Use `{#if}` blocks or dynamic element for level selection
   - Since Svelte does not have dynamic element tags, use `{#if level === 1}...{:else if level === 2}...{/if}` pattern

4. Create `frontend/src/lib/components/layout/Text.svelte`:
   - Accept standard Marionette props
   - Import `getData` from `$lib/store/data.svelte`
   - Text content: if `bind`, use `getData(surface, bind) as string`; else `props.text`
   - Render: `<p class="text-sm leading-[1.5]">{text}</p>` (Body from UI-SPEC: 14px/400/1.5)
   - If `props.variant === 'label'`: `class="text-sm font-semibold leading-[1.4]"` (Label from UI-SPEC)
   - If `props.inline`: render `<span>` instead of `<p>`

5. Create `frontend/src/lib/components/feedback/Spinner.svelte`:
   - Accept standard Marionette props
   - Import `Spinner as FlowbiteSpinner` from `flowbite-svelte`
   - Props: `props.size` (default '8'), `props.color` (default 'primary')
   - Render: `<FlowbiteSpinner size={props.size} color={props.color} />`

6. Create `frontend/src/lib/components/feedback/ErrorDisplay.svelte`:
   - Accept standard Marionette props
   - Import `getData` from `$lib/store/data.svelte`
   - Import `Alert` from `flowbite-svelte`
   - Import `ExclamationCircleOutline` from `flowbite-svelte-icons`
   - Read errors from `bind` pointer (array of `{ path?: string, message: string }`)
   - If no errors or empty array, render nothing
   - Render each error: `<Alert color="red" class="mb-2"><ExclamationCircleOutline slot="icon" class="w-5 h-5" />{error.message}</Alert>`
   - If error has `path`, show path in smaller text: `<span class="text-xs text-red-400">{error.path}</span>`
