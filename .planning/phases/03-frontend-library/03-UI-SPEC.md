# Phase 3 -- UI Design Contract

> Visual and interaction contract for the Marionette Svelte component library. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Flowbite Svelte, not shadcn) |
| Preset | not applicable |
| Component library | Flowbite Svelte 1.31.0 |
| Icon library | flowbite-svelte-icons 3.1.0 |
| Font | System font stack (Flowbite default: Inter via Tailwind) |

**Note:** This phase builds a component library, not an application screen. Flowbite Svelte handles all visual styling for interactive controls. This contract governs Marionette's own visual elements: surface layout, fallback components, error boundaries, loading skeletons, and toast/modal overlays.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, inline padding within compact controls |
| sm | 8px | Spacing between form fields in compact layouts, chip padding |
| md | 16px | Default gap between sibling components in adjacency list rendering |
| lg | 24px | Surface internal padding (main, sidebar content area) |
| xl | 32px | Gap between major sections within a surface |
| 2xl | 48px | Sidebar width gutter from main content |
| 3xl | 64px | Not used in this phase |

Exceptions: Touch targets for nav-items and buttons use minimum 40px height (Flowbite default, no override needed).

---

## Typography

Flowbite Svelte inherits Tailwind's default type scale. Marionette library elements use these specific values:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 500 (medium) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

**Weights used:** 400 (body, descriptions) and 600 (headings, labels, CTAs). Flowbite components may use 500 internally; do not override.

**Monospace:** Fallback component props dump uses `font-mono` at 12px, weight 400, line-height 1.4.

## Color

Flowbite Svelte provides a full color system via Tailwind. Marionette library elements use these semantic roles:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-white` / `dark:bg-gray-900` | Surface backgrounds (main, sidebar, modal backdrop body) |
| Secondary (30%) | `bg-gray-50` / `dark:bg-gray-800` | Card surfaces, sidebar background, table header row, nav background |
| Accent (10%) | `bg-primary-600` / Flowbite primary | See reserved-for list below |
| Destructive | `bg-red-600` | Delete buttons, destructive confirmation dialogs only |

Accent reserved for:
- Active nav-item highlight (left border or background)
- Primary action buttons ("Save", "Submit", "Add")
- Loading spinner stroke color
- Focus ring on form inputs
- Toast icon for success variant

**Fallback component (dev mode):** `border-red-500` 2px dashed border, `bg-red-50` background, `text-red-700` text. This is intentionally loud -- it signals an unregistered component type during development.

**Error boundary:** `border-orange-400` 1px solid border, `bg-orange-50` background, `text-orange-700` text. Distinguishable from fallback (orange vs red).

## Component Visual Contracts

These define how Marionette's own structural components look (beyond what Flowbite provides).

### Surface Layout

```
+----------------------------------------------------------+
|  [sidebar: 256px fixed]  |  [main: fluid, min 320px]     |
|  bg-gray-50              |  bg-white                      |
|  border-r border-gray-200|  p-24px (lg token)             |
|  p-16px (md token)       |                                |
|  overflow-y: auto        |  overflow-y: auto              |
+----------------------------------------------------------+
|  [modal: centered overlay, max-w per size prop]           |
|  backdrop: bg-black/50, z-50                              |
+----------------------------------------------------------+
|  [toast: top-right stack, 16px from edge, z-60]           |
|  max-width: 384px, gap: 8px between stacked toasts        |
+----------------------------------------------------------+
```

### NodeRenderer

- No visual output of its own -- purely structural
- Passes `class` prop through to rendered component if present
- Wraps each node in an error boundary (invisible unless error occurs)

### Fallback Component (Unknown Type)

- Border: 2px dashed `red-500`
- Background: `red-50`
- Padding: 16px (md token)
- Heading: "Unknown component: {type}" in `red-700`, 14px semibold
- Body: JSON.stringify(props, null, 2) in monospace 12px, `red-600`
- Only rendered in dev mode; in production, render nothing and log warning

### Error Boundary

- Border: 1px solid `orange-400`
- Background: `orange-50`
- Padding: 16px (md token)
- Icon: ExclamationTriangle from flowbite-svelte-icons, 20px, `orange-500`
- Text: "Something went wrong rendering this component." in 14px regular, `orange-700`
- Below text: "Try refreshing the page." in 12px regular, `orange-500`

### Loading Skeleton

- Animated pulse (Tailwind `animate-pulse`)
- Rounded rectangles matching expected component dimensions
- Color: `bg-gray-200` / `dark:bg-gray-700`
- Border radius: 4px (rounded-sm)

### Modal Overlay

- Delegates to Flowbite `Modal` component
- Sizes mapped from protocol: sm=max-w-md, md=max-w-lg, lg=max-w-2xl
- Close on backdrop click: yes (send close-modal action to backend)
- Close on Escape: yes (send close-modal action to backend)

### Toast Surface

- Position: fixed top-right, 16px inset from viewport edge
- Stack direction: top-to-bottom (newest on top)
- Gap: 8px between toasts
- Auto-dismiss: 5000ms default (overridable via event payload `duration` field)
- Animation: fade-in from right on enter, fade-out to right on exit (200ms)
- Delegates to Flowbite `Toast` component for individual toast rendering
- Variants: success (green), error (red), warning (yellow), info (blue) -- mapped from event `severity` field

### Virtual Scroll Table

- Delegates to Flowbite `Table`, `TableHead`, `TableBody`, `TableHeadCell`, `TableBodyRow`, `TableBodyCell`
- Row height: 48px fixed (enables virtual scroll math)
- Visible buffer: 3 rows above and below viewport
- Chunk size: 50 rows per request to backend
- Prefetch trigger: when scroll position is within 2 chunks of unloaded region
- Sort indicator: ChevronUp / ChevronDown icons from flowbite-svelte-icons in table header cells
- Sortable column header: `cursor-pointer`, `hover:bg-gray-100`

## Interaction Contracts

### WebSocket Reconnection

- Initial reconnect delay: 1000ms
- Backoff multiplier: 2x
- Maximum delay: 30000ms
- Jitter: +/- 20% random
- Maximum retries: unlimited (keep trying forever)
- During reconnection: show "Connection lost. Reconnecting..." banner at top of main surface, `bg-yellow-50`, `text-yellow-800`, 14px, with animated spinner

### Dirty Field Tracking

- Mark dirty: on `focus` event
- Clear dirty: on `blur` event
- While dirty: queue incoming patches for that JSON Pointer path
- On blur: apply all queued patches for that path in order

### Optimistic Updates

- On action with `optimistic.patch`: snapshot affected paths, apply patch immediately
- On error response correlated to that action: restore snapshot
- No visual indicator for optimistic state (it should feel instant)

### Focus Management

- Modal open: focus first focusable element inside modal
- Modal close: restore focus to element that triggered the modal open
- Toast: never steal focus
- Navigation: after render of new main surface content, focus the main surface container (not a specific element)
