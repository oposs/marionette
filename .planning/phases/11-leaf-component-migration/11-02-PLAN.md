Migrate each component following the pass-through pattern (D-01). Preserve the SDUI interface contract (`surface`, `props`, `bind`, `action`, `children`) on every component.

**Button.svelte:**
- Import `Button as ShadcnButton` from `$lib/components/ui/button`
- Import `getIcon` from `$lib/registry/icons` for icon support
- Import `Loader2` from `@lucide/svelte/icons/loader-2` for loading state
- Map `props.color === 'red'` to `variant="destructive"`, `props.outline === true` to `variant="outline"`, default to `variant="default"`
- Render icon if `props.icon` is set: `{@const IconComp = getIcon(props.icon as string)}` then render `<IconComp class="size-4" />` inside the button before label text
- Icon+label gap: use shadcn Button which already handles flex layout; add `gap-2` class if icon present
- Icon-only: if `props.label` is falsy but `props.icon` is set, use `size="icon"` and add `aria-label` from `props.ariaLabel ?? props.label ?? props.icon` (per UI-SPEC)
- Loading state: if `props.loading` is truthy, replace icon with `<Loader2 class="size-4 animate-spin" />` and set `disabled`
- Keep ALL existing `handleClick` logic including optimistic updates and `getAllData(surface)` payload merge
- Remove the manual `colorClass` derived and all inline Tailwind styling that duplicates shadcn variant behavior

**TextInput.svelte:**
- Import `Input` from `$lib/components/ui/input`
- Import `Label` from `$lib/components/ui/label`
- Wrap in a `<div class="grid w-full gap-2">` (8px gap per UI-SPEC)
- Render `<Label class="font-semibold">{props.label}</Label>` when `props.label` exists (font-semibold per UI-SPEC typography: 600 weight for labels)
- Replace the `<input>` element with `<Input type={...} placeholder={...} value={...} oninput={handleInput} onfocus={handleFocus} onblur={handleBlur} class={fieldError ? 'border-destructive' : ''} disabled={...} required={...} />`
- Error message: `<p class="text-xs text-destructive">{fieldError}</p>` (text-xs per UI-SPEC Small typography: 12px)
- Helper text: `<p class="text-xs text-muted-foreground">{props.helperText}</p>`
- Keep ALL existing bind/dirty/blur logic unchanged

**SelectInput.svelte:**
- Import `* as Select` from `$lib/components/ui/select`
- Import `Label` from `$lib/components/ui/label`
- Replace native `<select>` with shadcn Select composable (per D-03, Pitfall 1)
- Use `<Select.Root type="single" value={value} onValueChange={handleValueChange}>` -- NOT native onchange
- Create `handleValueChange(newValue: string)` that calls `setData(surface, bind, newValue)` and dirty tracking
- `<Select.Trigger class="w-full">` with `<span>` showing selected label or placeholder in `text-muted-foreground`
- `<Select.Content>` with `{#each options as opt}<Select.Item value={opt.value} label={opt.label} />{/each}`
- Label above trigger: `<Label class="font-semibold">` when `props.label` exists
- Wrap in `<div class="grid w-full gap-2">`
- Remove `handleChange`, `handleFocus`, `handleBlur` (native select events) -- replace with `onValueChange` callback
- Keep `markDirty`/`clearDirty` logic: call `markDirty(bind)` on open and `clearDirty` on value change

**Checkbox.svelte:**
- Import `Checkbox as ShadcnCheckbox` from `$lib/components/ui/checkbox`
- Import `Label` from `$lib/components/ui/label`
- Replace native `<input type="checkbox">` with `<ShadcnCheckbox checked={checked} onCheckedChange={handleCheckedChange} disabled={props.disabled as boolean} />`
- Create `handleCheckedChange(val: boolean | 'indeterminate')` that calls `setData(surface, bind, val === true)` (per Pitfall 5 -- onCheckedChange, not onchange)
- Layout: `<div class="flex items-center gap-2">` for 8px gap (per UI-SPEC)
- Label: `<Label class="font-semibold">{props.label}</Label>` next to checkbox, same line

**Form.svelte:**
- Read current Form.svelte first. It is likely already minimal (just renders children in a form tag).
- Keep as-is if it has no Flowbite imports. Only update if it has hardcoded color classes that aren't semantic tokens.
