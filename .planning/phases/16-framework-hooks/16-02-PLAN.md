<objective>
Implement the `#[gallery_demo]` attribute proc macro in `marionette-macros`. The macro accepts optional `key = "..."` and `name = "..."` args, validates that the annotated item is a `pub fn Name() -> Node` (no args, no generics, no async, no where-clause, returns `Node`), and emits two cfg-gated items: the original fn (with `#[cfg(feature = "gallery")]` prepended) and a `#[linkme::distributed_slice(::marionette::gallery::DEMOS)]` static of type `::marionette::gallery::DemoEntry`.

Purpose: FRAME-01's auto-discovery spine. Misuse produces a clear compile error naming the violated rule. `darling` handles the attribute args (same library as `component_builder.rs`); `syn` handles the signature/visibility/item-kind validation. Title-casing runs at macro expansion time so the emitted `display_name` is a `&'static str` literal (no runtime allocation).

Output: new `gallery_demo.rs` (~220 LoC including inline tests); modified `lib.rs` (two additions: `mod gallery_demo;` + `#[proc_macro_attribute] pub fn gallery_demo`). Covers FRAME-01; locks D-B1, D-C1, D-C3, D-C4.

The macro emits `::marionette::gallery::DemoEntry` / `::marionette::gallery::DEMOS` / `::marionette::gallery::__linkme::distributed_slice` paths as tokens — expansion does NOT type-check them at macro-crate compile time. The paths only need to resolve when a CONSUMER (gallery-smoke in Plan 03) tries to use the macro. Plans 01 and 02 touch disjoint files and compile independently.

    ```rust
    use darling::FromMeta;
    use darling::ast::NestedMeta;
    use proc_macro2::{Span, TokenStream};
    use quote::quote;
    use syn::{Ident, ItemFn};

    /// Attribute arguments for `#[gallery_demo(key = "...", name = "...")]`.
    ///
    /// Both args are optional. When absent, `key` defaults to the annotated fn's
    /// ident as a string, and `name` defaults to the title-cased form of `key`
    /// per `title_case()`.
    #[derive(FromMeta, Default)]
    struct GalleryDemoOpts {
        #[darling(default)]
        key: Option<String>,
        #[darling(default)]
        name: Option<String>,
    }

    /// Entry point. Parses attribute args, validates the annotated item, and
    /// emits the cfg-gated fn + cfg-gated linkme static.
    pub fn gallery_demo_impl(attr: TokenStream, item: TokenStream) -> TokenStream {
        // 1. Parse attribute args via darling.
        let meta_list = match NestedMeta::parse_meta_list(attr) {
            Ok(v) => v,
            Err(e) => return darling::Error::from(e).write_errors(),
        };
        let opts = match GalleryDemoOpts::from_list(&meta_list) {
            Ok(v) => v,
            Err(e) => return e.write_errors(),
        };

        // 2. Parse the annotated item. Explicit failure branch so
        //    "applied to non-fn" produces a targeted error.
        let func: ItemFn = match syn::parse2::<ItemFn>(item.clone()) {
            Ok(v) => v,
            Err(_) => {
                return syn::Error::new_spanned(
                    item,
                    "#[gallery_demo] can only be applied to `pub fn` items \
                     (not structs, enums, modules, or other items)",
                )
                .to_compile_error();
            }
        };

        // 3. Validate signature + visibility.
        if let Err(e) = validate_item(&func) {
            return e.to_compile_error();
        }

        // 4. Derive key + display_name.
        let fn_ident = &func.sig.ident;
        let key = opts.key.unwrap_or_else(|| fn_ident.to_string());
        let display_name = opts.name.unwrap_or_else(|| title_case(&key));

        // 5. Synthesize a unique static ident per annotation site.
        let static_ident = Ident::new(
            &format!("__GALLERY_DEMO_{fn_ident}"),
            fn_ident.span(),
        );

        // 6. Emit cfg-gated fn + cfg-gated linkme static (D-B1).
        //    The linkme path re-routes through marionette::gallery::__linkme
        //    so consumer crates don't need their own `linkme` dep.
        quote! {
            #[cfg(feature = "gallery")]
            #func

            #[cfg(feature = "gallery")]
            #[::marionette::gallery::__linkme::distributed_slice(::marionette::gallery::DEMOS)]
            static #static_ident: ::marionette::gallery::DemoEntry =
                ::marionette::gallery::DemoEntry {
                    key: #key,
                    render: #fn_ident,
                    display_name: #display_name,
                };
        }
    }

    /// Validate that `func` is `pub fn name() -> Node` with no args, no generics,
    /// no async, no where-clause. Returns the first violation as a spanned error.
    fn validate_item(func: &ItemFn) -> Result<(), syn::Error> {
        // Visibility.
        if !matches!(func.vis, syn::Visibility::Public(_)) {
            return Err(syn::Error::new_spanned(
                &func.sig.ident,
                "#[gallery_demo] requires `pub fn` visibility (found private fn)",
            ));
        }

        // Arguments.
        if !func.sig.inputs.is_empty() {
            return Err(syn::Error::new_spanned(
                &func.sig.inputs,
                format!(
                    "#[gallery_demo] fn must be `fn() -> Node` with zero arguments (found {})",
                    func.sig.inputs.len()
                ),
            ));
        }

        // async.
        if func.sig.asyncness.is_some() {
            return Err(syn::Error::new_spanned(
                func.sig.asyncness,
                "#[gallery_demo] fn must not be async",
            ));
        }

        // Generics.
        if !func.sig.generics.params.is_empty() {
            return Err(syn::Error::new_spanned(
                &func.sig.generics,
                "#[gallery_demo] fn must not have generic parameters",
            ));
        }

        // where-clause.
        if func.sig.generics.where_clause.is_some() {
            return Err(syn::Error::new_spanned(
                &func.sig.generics.where_clause,
                "#[gallery_demo] fn must not have a where-clause",
            ));
        }

        // Return type must end in `Node`.
        match &func.sig.output {
            syn::ReturnType::Default => Err(syn::Error::new_spanned(
                &func.sig,
                "#[gallery_demo] fn must return `Node` (found unit return type)",
            )),
            syn::ReturnType::Type(_, ty) => {
                if return_type_is_node(ty) {
                    Ok(())
                } else {
                    Err(syn::Error::new_spanned(
                        ty,
                        "#[gallery_demo] fn must return `Node` (an alias for \
                         `(String, marionette_protocol::Component)`)",
                    ))
                }
            }
        }
    }

    /// True if `ty` is a path whose last segment ident equals `Node`.
    /// Accepts `Node`, `marionette::gallery::Node`, `crate::Node`, etc.
    fn return_type_is_node(ty: &syn::Type) -> bool {
        if let syn::Type::Path(p) = ty {
            if let Some(last) = p.path.segments.last() {
                return last.ident == "Node";
            }
        }
        false
    }

    /// ASCII title-casing for default `display_name`.
    ///
    /// Splits on `-` and `_`, filters empty chunks, uppercases the first ASCII
    /// char of each chunk, joins with a single space. Non-ASCII characters pass
    /// through untouched (e.g. `"OKLCH-swatches"` → `"OKLCH Swatches"` — the
    /// already-upper `"OKLCH"` tail survives because only the first char is
    /// touched).
    fn title_case(key: &str) -> String {
        key.split(|c: char| c == '-' || c == '_')
            .filter(|s| !s.is_empty())
            .map(|word| {
                let mut chars = word.chars();
                match chars.next() {
                    None => String::new(),
                    Some(c) => {
                        let mut s = String::with_capacity(word.len());
                        s.extend(c.to_uppercase());
                        s.push_str(chars.as_str());
                        s
                    }
                }
            })
            .collect::<Vec<_>>()
            .join(" ")
    }

    // Silence proc-macro2's Span-is-unused lint when no gate fires during tests.
    #[allow(dead_code)]
    fn _span_check() -> Span { Span::call_site() }

    #[cfg(test)]
    mod tests {
        use super::title_case;

        #[test]
        fn title_case_single_word() {
            assert_eq!(title_case("button"), "Button");
        }

        #[test]
        fn title_case_hyphenated() {
            assert_eq!(title_case("text-input"), "Text Input");
        }

        #[test]
        fn title_case_underscored() {
            assert_eq!(title_case("data_table"), "Data Table");
        }

        #[test]
        fn title_case_preserves_mixed_case_tail() {
            assert_eq!(title_case("OKLCH-swatches"), "OKLCH Swatches");
        }

        #[test]
        fn title_case_empty_string() {
            assert_eq!(title_case(""), "");
        }

        #[test]
        fn title_case_trailing_separator() {
            assert_eq!(title_case("foo-"), "Foo");
        }

        #[test]
        fn title_case_double_separator() {
            assert_eq!(title_case("foo--bar"), "Foo Bar");
        }
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compile-time | proc-macro runs arbitrary code during consumer compilation; all proc macros carry this trust. The macro reads only the annotated fn's AST — no file reads, no network, no env access. |
| token-emission | the macro emits tokens referencing `::marionette::gallery::*` paths; if a malicious consumer shadows `marionette`, emitted code resolves to their paths (standard Rust hygiene limitation, not specific to this macro). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-02-01 | Tampering | proc-macro code injection via crafted attr input | accept | `darling` uses structural AST parsing, not string interpolation. Attribute input is parsed via `NestedMeta::parse_meta_list` which rejects arbitrary token streams. Unknown fields produce darling's standard error. syn-based signature validation rejects any non-conforming fn body. |
| T-16-02-02 | Tampering | attacker shadows `marionette::gallery` to hijack emitted token paths | accept | Standard Rust name-resolution; impossible to defend at macro level. Consumer crates control their own `use` resolution. Non-attackable in the Phase 16 trust envelope (proc macros are compiled from workspace source, not downloaded at build time). |
| T-16-02-03 | Information disclosure | compile-error messages leak project-internal paths or state | accept | `syn::Error::new_spanned` uses the standard rustc diagnostic path. Error messages are developer-authored strings (e.g. "requires `pub fn` visibility") — no runtime data, no env vars, no paths. |
| T-16-02-04 | Denial of Service | pathological input (extremely long fn signature, deeply nested generics) slows macro expansion | accept | proc-macro expansion has a rustc-level timeout. The macro performs O(1) validation of the signature (no recursion). Pathological input from a malicious workspace-local crate is out of the threat model (we trust workspace source). |
| T-16-02-05 | Elevation of privilege | macro emits unintended code visible in the generated fn | mitigate | All emitted tokens are within the `quote!` block. The original fn body is embedded as `#func` (syn-parsed, not string-interpolated — cannot contain extra tokens). The static's fields are all const-legal `&'static str` / `fn` values. No `unsafe` blocks emitted. |
