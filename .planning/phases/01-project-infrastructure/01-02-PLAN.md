    Create `Makefile` at repo root with these exact targets:

    ```makefile
    .PHONY: dev build test lint clean format

    dev:
    	@echo "Starting development servers..."
    	@trap 'kill 0' EXIT; \
    	cd backend && cargo run -p crm-demo & \
    	cd frontend && npm run dev & \
    	wait

    build:
    	cd backend && cargo build --release
    	cd frontend && npm run build

    test:
    	cd backend && cargo test
    	cd frontend && npm test -- --run

    lint:
    	cd backend && cargo fmt --check
    	cd backend && cargo clippy -- -D warnings
    	cd frontend && npm run lint
    	cd frontend && npm run check

    format:
    	cd backend && cargo fmt
    	cd frontend && npm run format

    clean:
    	cd backend && cargo clean
    	cd frontend && rm -rf .svelte-kit build node_modules/.vite
    ```

    Key details:
    - `dev` target: trap/background/wait pattern must be in a SINGLE recipe line using `; \` continuation so trap applies to the subshell containing both background processes.
    - `test` target: `npm test -- --run` passes `--run` to vitest to run once (not watch mode).
    - `lint` target: four checks -- `cargo fmt --check`, `cargo clippy -- -D warnings`, `npm run lint` (ESLint), `npm run check` (svelte-check).
    - Tabs for Makefile indentation (not spaces).

    After creating, run `make build` and `make test` and `make lint` to verify all targets work.
